### 도메인 이름(Domain Name)이란?
도메인 이름은 영문과 숫자로 된 복잡한 IP 주소를 사람이 기억하고 찾기 쉽게 문자로 바꾼 인터넷 주소이다.
* **ex)** 스마트폰 주소록에서 복잡한 전화번호 대신 '홍길동'이라는 이름을 저장해 두고 전화를 거는 것과 같은 원리.
* **실제 주소:** `192.0.2.2` 같은 기계용 IP 주소
* **인간용 주소:** `google.com` 같은 도메인 이름

---

### 도메인 이름 vs URL 차이점
많이들 혼동하지만, 도메인 이름은 URL의 '일부분'에 불과하다.

* **도메인 이름:** `cloudflare.com` ➔ 인터넷상에서 특정 컴퓨터(서버)가 어디에 있는지를 나타내는 고유 주소.
* **URL (웹 주소):** `https://cloudflare.com/learning/` ➔ 프로토콜(`https`), 도메인 이름, 그리고 서버 내부의 세부 페이지 경로(`/learning/`)까지 전부 싹 다 적어놓은 전체 주소.

### 도메인의 우측 우선 계층 구조
도메인은 오른쪽에서 왼쪽으로 갈수록 더 구체적인 주소를 나타내며, 점(`.`)을 기준으로 계층이 나뉜다.


#### 일반적인 도메인의 예시: `google.com`
* **TLD (최상위 도메인):** `.com` ➔ 맨 오른쪽 끝부분. 주소의 가장 일반적인 카테고리를 나타냄. (ex. `.com`, `.net`, 국가별 `.kr`, `.jp` 등)
* **2LD (차상위 도메인):** `google` ➔ TLD 바로 왼쪽 부분. 사용자가 직접 비용을 내고 등록하는 핵심 브랜드 이름.

#### 조금 더 복잡한 도메인의 예시: `google.co.uk` (구글 영국 주소)
* **TLD (최상위 도메인):** `.uk` (영국 국가 도메인)
* **2LD (차상위 도메인):** `.co` (회사 조직을 뜻함)
* **3LD (3차 도메인 / 하위 도메인):** `google` (가장 구체적인 브랜드 이름)

### 도메인 이름 관리와 보안 (상식)
* **도메인 관리:** 전 세계 도메인은 기본적으로 큰 장부(도메인 레지스트리)를 통해 관리되며, 우리는 고대디, 가비아 같은 **'등록기관(Registrar)'**을 통해 일정 기간 돈을 내고 주소를 임대해서 쓴다.
