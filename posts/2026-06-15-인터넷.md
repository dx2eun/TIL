# 인터넷
### 네트워크란?
네트워크는 서로 연결된 여러 기기, 컴퓨터의 그룹이다.
```
ex)컴퓨터나 스마트폰 같은 기기들이 서로 데이터를 주고받을 수 있도록 연결해 놓은 상태나 망
```
### 인터넷이란?
인터넷은 네트워크들이 서로 연결되면 인터넷을 형성하는것이다.

## 인터넷은 어떻게 작동하는가
인터넷은 표준화된 프로토콜들을 사용하는 기기를 컴퓨팅 시스템과 연결해 작동 시키는것이다.
이런 프로토콜들은 안전한 정보 전송과 정보를 정의하는것을 돕는다.
```
ex)
표준화된 프로토콜을 사용하는 기기 : 핸드폰,컴퓨터
컴퓨팅 시스템: 서버
```

인터넷의 핵심은 상호연결된 라우터의 글로벌 네트워크(라우터로 연결된 거대한 통신망)이다. 라우터로 다른 기기와 연결하고 전송할 데이터를 작은 패킷으로 나누고 전송한다.
